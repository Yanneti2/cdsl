# Compact Data Structures Library Unitary Tests

This directory contains the test code files for all the implementations on this library. 

After you execute `make` inside your build directory, a executable of all this files will be waiting for you on build/tests/.

 * `balanced_parenthesis-tester` - Balanced Parentheses Tree operators and logic
 * `bitvector-tester` - some bitvector operations and constructors 
 * `huffman-tester` - Huffman Tree algorithm logic
 * `jacobson-tester` - jacobson structure logic
 * `utils-tester` - basic bit operations

See [main README](../README.md) on how to compile these files with cmake.
