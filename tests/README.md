# Compact Data Structures Library Unitary Tests

This directory contains the test code files, functionality tests with assert function, for all the implementations on this library. 

After you execute `make` inside your build directory, a executable of all this files will be waiting for you on build/tests/.

 * `balanced_parenthesis-tester` - Balanced Parentheses Tree structure and logic operators
 * `bitvector-tester` - some bitvector operations and constructors 
 * `huffman-tester` - Huffman Tree algorithm logic
 * `louds-tester` - LOUDS tree structure and logic operations
 * `RRR-tester` - Raman, Raman, and Rao structure
 * `wt-tester` - WaveletTree structure and operations

See [main README](../README.md) on how to compile these files with cmake.
